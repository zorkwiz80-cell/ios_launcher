# iLauncher — лаунчер для Android 16 в стиле iOS 18

## Что внутри
- Сетка иконок 4×6 с iOS-скруглением (≈22,4 %), подписи с тенью, постраничная прокрутка
- Док из 4 приложений (телефон, сообщения, браузер, камера — определяются автоматически)
- Индикатор страниц над доком
- Библиотека приложений — последняя страница: карточки по категориям с мини-иконками 2×2
- Долгое нажатие на иконку: меню «Открыть / О приложении / Удалить»
- Анимация открытия приложения «из иконки»
- Светлая и тёмная темы по системной настройке (в тёмной — монохромные иконки Android 13+ на тёмных плитках)
- Собственные нарисованные иконки для телефона, сообщений, браузера, камеры и настроек
- Обои системы просвечивают, прозрачные статус-бар и навигация (edge-to-edge)
- Кнопка Home / Назад возвращает на первую страницу

Иконки Apple не используются — берутся иконки ваших установленных приложений.

## Сборка
1. Откройте папку `IOSLauncher` в Android Studio (Ladybug или новее) — он сам создаст Gradle wrapper и скачает зависимости.
2. Run ▶ на устройстве или эмуляторе с Android 13+ (targetSdk 36 = Android 16).
3. Нажмите Home и выберите «iLauncher» → «Всегда».

## Ограничения / что можно добавить дальше
- Нет блюра дока и режима редактирования (покачивание иконок, перетаскивание, папки, виджеты).
- Расположение иконок не сохраняется: сортировка по алфавиту.
- Проект не собирался в среде создания (нет Android SDK и сети), поэтому первая сборка может потребовать мелких правок.
